# Wordle TR word lists

Two plain JSON arrays of lowercase strings, sorted with Turkish collation (`localeCompare(…, 'tr')`):

| File | Words | What it is |
| --- | --- | --- |
| `valid.json` | 11,431 | Every accepted 5-letter guess. Inflected forms are allowed (`evler`, `geldi`, `gitti`). |
| `answers.json` | 1,957 | Possible answers: common, everyday **base words** (`kalem`, `bahçe`, `deniz`, `kitap`, `çiçek`, `yalan`, `şeker`). Every answer is also in `valid.json`. |

Each word is exactly 5 Unicode code points from the Turkish alphabet
`a b c ç d e f g ğ h ı i j k l m n o ö p r s ş t u ü v y z`, NFC, lowercased with
`toLocaleLowerCase('tr')` (so `I → ı`, `İ → i`). `â/î/û` become `a/i/u`, and the results are deduplicated.

The raw hunspell `.dic` (36 MB) and `tr_full.txt` (30 MB) are too big to keep, so only their 5-letter subsets are stored.
These subsets are generated by `build.mjs` (see below), and each file's header names its source.
All downloaded files are only read as text and parsed by `build.mjs`. Nothing from them is executed.

## Rebuilding

```sh
node content/wordle/build.mjs        # uses only source/ + curation/ (deterministic)
node content/wordle/validate.mjs     # checks; exit code 1 on failure
```

To regenerate the two subsets from the raw upstream files:

```sh
curl -LO https://raw.githubusercontent.com/tdd-ai/hunspell-tr/7302eca5f3652fe7ae3d3ec06c44697c97342b4e/tr_TR.dic
curl -LO https://raw.githubusercontent.com/tdd-ai/hunspell-tr/7302eca5f3652fe7ae3d3ec06c44697c97342b4e/tr_TR.aff
curl -LO https://raw.githubusercontent.com/hermitdave/FrequencyWords/525f9b560de45753a5ea01069454e72e9aa541c6/content/2018/tr/tr_full.txt
node content/wordle/build.mjs --hunspell tr_TR.dic tr_TR.aff --subtitles tr_full.txt
```

There are two tunables, both environment variables: `WORDLE_VALID_MIN_FREQ` (default 5) and `WORDLE_MIN_FREQ` (default 60).

## Filtering rules

**Normalisation (every source):** NFC → trim → `toLocaleLowerCase('tr')` → `â/î/û → a/i/u`.
A word is kept only if it is 5 code points, all from the Turkish alphabet. This drops spaces, hyphens, apostrophes, digits, dots and q/w/x.

**Wiktionary lemmas:**
- Multi-word, hyphenated, apostrophe and dotted entries are skipped.
- Entries that start with a capital letter are proper nouns or abbreviations (`Abana`, `TDK`). They go into a blocklist, unless the same word also exists in lowercase (`Mart`/`mart`).
- Infinitives ending in `-mak/-mek` also produce their stem (`anlatmak → anlat`, `beklemek → bekle`).

**valid.json** =
(hunspell forms seen ≥ 5 times in the subtitles) ∪ Wiktionary lemmas ∪ Wiktionary verb stems ∪ `answers.json`,
minus the proper-noun blocklist and `curation/valid-exclude.txt`.
- Why the subtitle check: tdd-ai/hunspell-tr is a compressed full-form list. Its "stems" are arbitrary prefixes (`abanm` + `a/ak`), and it contains lowercased names and abbreviations (`abd` + `ca`). On its own it would accept nonsense like `abanm` or `abdca`. Requiring the word to also appear in subtitles removes most of that. Requiring hunspell (or Wiktionary) removes subtitle typos and foreign words.
- `curation/valid-exclude.txt`: personal first names that are not also ordinary words (`ahmet`, `fatma`, …). Names that are ordinary words stay valid (`deniz`, `umut`, `murat`, `aydın`).

**answers.json** = Wiktionary lemmas/verb stems that are in valid.json and occur ≥ 60 times in the subtitles,
minus `curation/answers-exclude.txt`, plus `curation/answers-include.txt`.
- The ≥ 60 cut-off produced 2,815 candidates. All of them were read by hand, and about 900 were excluded, in these groups:
  - proper nouns and names
  - inflected or conjugated forms that are also lemmas (`verdi`, `bende`, `orada`, `gelen`)
  - verbal nouns and negative imperatives (`bakma`, `gitme`), and rare infinitives (`ummak`, `itmek`)
  - causatives and fragments
  - vulgar, sexual or slur words
  - archaic, Ottoman, religious-technical, dialect or very technical words
- `answers-include.txt`: 53 everyday or culturally Turkish words that subtitles under-represent (`tahin`, `aşure`, `salep`, `cezve`, `halay`, `kombi`, `kasko`, `dünür`…).

## Notes / known limitations

- `valid.json` still has some noise from the hunspell + subtitle intersection: rare dialect forms, a few uncommon names, odd truncations like `olmay`, and misspellings like `secim`. This is harmless for a guess list: it only makes the game a bit more permissive.
- The licences carry obligations:
  - Wiktionary content and OpenSubtitles-derived counts are CC BY-SA. Keep the attribution above. The derived lists are best treated as CC BY-SA 4.0 too.
  - The hunspell subset is MPL-2.0. Its licence file is kept next to it.
